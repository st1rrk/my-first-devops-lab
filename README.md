# My First devops lab
## About
A small project to experience automation, github and linux practices.
## Objectives
To establish an automated pipeline that runs few linux commands whenever there's a change made to the github repository.
## Technologies
+ Github
+ Github actions
+ Ubuntu linux
+ YAML
